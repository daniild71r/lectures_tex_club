\textbf{(13.2) Найдите все неприводимые многочлены (со стар. коэффициент 1) степени 2, 3 над полем
а) $\mathbb{F}_2$, б) $\mathbb{F}_3$.}

\textbf{а):}

Рассмотрим в общем виде многочлен второй степени: $f(x) = x^2 + px + q$. 

$f(0) = q \neq 0 \Rightarrow q = 1, f(1) = 1 + p + q = p \Rightarrow p = 1$. Значит, единственный подходящий многочлен: $x^2 + x + 1$.

Рассмотрим в общем виде многочлен третьей степени: $g(x) = x^3 + ax^2 + bx + c$, $g(0) = c \neq 0 \Rightarrow c = 1$

$g(1) = 1 + a + b + c = a + b \neq 0$. Значит, подходят пары $a = 0, b = 1$ и $a = 1, b = 0$.

В итоге имеем многочлены $x^3 + x^2 + 1, x^3 + x + 1$.

\textbf{б)}

Рассмотрим в общем виде многочлен второй степени: $f(x) = x^2 + px + q$. 

$f(0) = q \neq 0$. 
\begin{itemize}
    \item Если $q = 2$, то, $f(1) = 1 + p + 2 = p \neq 0$, $f(2) = 1 + 2p + 2 = 2p \neq 0$. Подходят $p = 1, p = 2$.
    \item Если $q = 1$, то $f(1) = 1 + p + 1 = p + 2 \neq 0$, т.е. $p \neq 1$. $f(2) = 1 + 2p + 1 \neq 0$, т.е. $p \neq 2$. Значит, $p = 0$.
\end{itemize}

Получаем многочлены: $x^2 + 1, x^2 + x + 2, x^2 + 2x + 2$.\\

Рассмотрим в общем виде многочлен третьей степени: $g(x) = x^3 + ax^2 + bx + c$, $g(0) = c \neq 0$

\begin{itemize}
    \item $c = 1$, тогда $f(1) = a + b + 2 \neq 0$, т.е. $a + b \neq 1$
    
    $f(2) = 2 + a + 2b + 1 = a + 2b \neq 0$
    
    Подходят пары $(a = 0, b = 2), (a = 1, b = 2), (a = 2, b = 0), (a = 2, b = 1)$
    \item $c = 2$, тогда $f(1) = a + b \neq 0$, $f(2) = a + 2b + 1 \neq 0$, т.е. $a + 2b \neq 2$
    
    Подходят пары: $(a = 0, b = 2), (a = 1, b = 0), (a = 1, b = 1), (a = 2, b = 2)$
\end{itemize}

Получаем многочлены: $x^3 + 2x + 1, x^3 + x^2 + 2x + 1, x^3 + 2x^2 + 1, x^3 + 2x^2 + x + 1, x^3 + 2x + 2, x^3 + x^2 + 2, x^3 + x^2 + x + 2, x^3 + 2x^2 + 2x + 2$
